# 产出验收标准与自评

本文件用于判定「本 Skill 产出的提示词」是否合格，以及对产出的提示词做基线对比。

## 合格门槛（全部满足才算通过）

| 维度 | 合格条件 | 不合格表现 |
|---|---|---|
| 覆盖率 | 五个必需槽位齐全 | 缺角色/背景/目标/约束/格式任一项 |
| 角色质量 | 含 ≥1 条可观察评判标准 | 只有「专家」「资深」等头衔 |
| 目标质量 | 祈使句 + ≥2 个可勾选必须项 | 「探讨一下」「帮我看看」 |
| 约束质量 | 覆盖 ≥2 类（禁用词/预算/语气/篇幅）且无互斥 | 无约束，或「详尽」与「极短」并存 |
| 格式质量 | 规定到可直接使用（含列名/结构） | 「排版好看点」 |
| 事实安全 | 领域档案仅给结构建议，无编造数据 | 档案里出现虚构的统计/法条/API |

任一维度不合格，回补对应槽位后重新交付。

## 自评清单（交付前勾选）

- [ ] 五槽齐全
- [ ] 角色含评判标准
- [ ] 目标已拆项
- [ ] 约束无互斥且数量合理
- [ ] 格式可直接用
- [ ] 已附领域适配说明
- [ ] 无编造领域事实

## 基线对比方法

验证本 Skill 是否带来真实增量：

1. 选一个典型任务（如「写咖啡馆营销方案需求」）。
2. 不带本 Skill，直接让模型写提示词，记录输出。
3. 带本 Skill，走五要素流程后再让模型写提示词，记录输出。
4. 对比：结构完整度、追问次数、模板化程度、约束覆盖、边界处理。

带 Skill 的输出必须在上述任一项存在可观察增量，否则应收窄定位或补信息，不能用文案包装替代真实价值。

## 未覆盖与降级

- 不验证领域事实真伪：档案只给结构，用户负责提供真实数据。
- 不替用户执行最终任务：本 Skill 只产出提示词。
- 当用户领域超出内置档案且拒绝提供细节时，按「其它领域」分支给出通用模板，并标注「未加载领域默认值」。
